① 本工具做什么（四大能力）

  • 格式校验：检查 SKILL.md 结构 / 字段规范
  • 语义清洗：去噪、统一表述、消歧
  • 冗余压缩：合并重复、精简资产
  • 调用效果追踪：记录真实调用与命中

② 5 个主视图

  • 简化：粘贴 / 拖拽 prompt → 一键压缩并给出 token 节省
  • 技能资产：浏览 / 校验你的技能仓库
  • 冲突检测：技能间规则冲突与消解
  • 数据看板：KPI 与覆盖度总览
  • 个性化：写入你常写、白费 token 的口癖，简化时默认消除

③ 个性化口癖怎么用

  • 进「个性化」页，把你常写、却白费 token 的话（如「请」「麻烦你」）写进清单
  • 之后每次在「简化」页压缩，都会默认自动消除这些口癖，无需反复勾选规则

      🗣️ 个性化 · 清掉你常写、却白费 token 的口癖
      
        
      
          每个人写 prompt 都有习惯性的多余词——比如开口就是「请」、动辄「麻烦你」、结尾「谢谢」。
          把它们写进下面的清单，以后每次简化都会默认自动消除，不用反复手动勾选规则。
        
      
        
      
          1 在输入框写一个口癖（如「请」）
          2 点「添加」入库
          3 去「简化」页粘贴 prompt，结果自动去口癖
          4 不想要了点「删除」
