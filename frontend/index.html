SkillForge · 个性化 Skill 资产优化工作台

① 本工具做什么（四大能力）

  • 格式校验：检查 SKILL.md 结构 / 字段规范
  • 语义清洗：去噪、统一表述、消歧
  • 冗余压缩：合并重复、精简资产
  • 调用效果追踪：记录真实调用与命中

② 5 个主视图

  • 简化：粘贴 / 拖拽 prompt → 一键压缩并给出 token 节省
  • 技能资产：浏览 / 校验你的技能仓库
  • 仿真沙盘：反事实调度 / 成本延迟仿真
  • 冲突检测：技能间规则冲突与消解
  • 数据看板：KPI 与覆盖度总览
  • 进化：自主进化闭环 + 趋势 + 账本

③ 如何运行「自主进化」

  • 进化视图点「▶ 运行自主进化」手动跑一轮
  • 或开「⚙ 自动进化」开关，后台周期自跑

④ 后端来源 与 自动进化开关

  • 后端：local-st(本地 OpenAI 兼容) / local-tfidf / openai
  • 「自动进化」开 = 后台周期自跑；关 = 仅手动

⑤ 进化账本 / 趋势图 怎么读

  • 账本：每次进化动作的时间线（含外部变化记录）
  • 趋势图：Gold 覆盖度 / F1 选对率 随时间连续演进（红点=异常，可点击看详情）
  • 「上次外部变化」：最近一次技能集增 / 删 / 改的清单与时间

      🧪 仿真沙盘 · 把「压缩省了多少」折算成钱和时间
      两个实验：调度反事实模拟验证「压缩后会不会选错技能」；成本/延迟仿真把节省的 常驻 token 折算成金额与延迟。都是离线估算，不真实调用模型。

      ⚠️ 冲突检测 · 找出「长得太像、容易选混」的技能
      两两比较所有技能的 description 语义相似度。 相似度超过阈值的一对，模型可能调错技能。可把高频冲突「沉淀为新规则」永久记录。
      1 选后端（默认 local-tfidf，零依赖） 2 拖「相似度阈值」滑块 3 点「重新计算」看冲突对 4 对有问题的点「沉淀为新规则」
